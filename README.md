# סימולטור אסטרטגיית פולבק RSI

אפליקציית Streamlit לבק-טסט וכוונון של אסטרטגיית "קניית פולבק במניות ענק בשוק עולה", על נתוני אמת מ-Yahoo Finance.
כל תנאי קבוע אפשר להפעיל/לכבות, וכל פרמטר משתנה אפשר לכוונן מהממשק.

> אין כאן ייעוץ השקעות. בק-טסט אינו הבטחה לעתיד.

## הפעלה מקומית

```bash
pip install -r requirements.txt
streamlit run app.py
```

הבדיקות האוטומטיות: `pip install pytest && pytest -q`

## פריסה עם GitHub + Streamlit Community Cloud

1. צור ריפו חדש ב-GitHub והעלה אליו את כל התיקייה (`app.py`, `simulator/`, `requirements.txt`, `.streamlit/`, `tests/`).
2. היכנס ל-<https://share.streamlit.io> עם חשבון GitHub ולחץ **Create app**.
3. בחר את הריפו, ענף `main`, וקובץ ראשי `app.py`. תחת **Advanced settings** בחר Python 3.11 או 3.12.
4. לחץ **Deploy**.

הערות:
- **הטעינה הראשונה** מורידה כ-500 מניות ואת נתוני מספר המניות ותאריכי הדוחות של המאגר, וכוללת כמה דקות. אחר כך הנתונים נשמרים בזיכרון האפליקציה (12 שעות), וכל הרצה נוספת לוקחת שניות. אם האפליקציה "נרדמת" או מופעלת מחדש, הטעינה חוזרת.
- Yahoo Finance מגביל קצב בקשות. אם ההורדה נכשלת, המתן דקה והרץ שוב, או הקטן את "גודל מאגר מועמדים".
- אפשר לעבוד גם על רשימת מניות קצרה משלך (מאגר: "רשימת מניות שאבחר"). זה מהיר בהרבה ומתאים לניסויים.

## מה ניתן לכוונן

**תקופה ומאגר:** תחילה/סיום, טופ N (נקודתי לפי שווי שוק, קבוע, או רשימה חופשית), גודל מאגר מועמדים, פיצול אימון/בדיקה.
**כניסה:** מדד מעל SMA (אורך), מניה מעל SMA (אורך), תקופת RSI וסף כניסה, חצייה בלבד או כל יום, PEG, סינון דוחות (ימים), אופן כניסה (Buy-stop או פתיחה), באפר בדולרים, תקרת קנייה, תוקף פקודה, הורדת ה-high, ביטול כשהתנאים נשברים.
**סיכון:** סטופ קבוע / ATR / ללא, RVOL (סף, חלון, יום כניסה או כל יום), עצירת זמן.
**יציאות:** RSI ואחוז מימוש ראשון, break-even, RSI מימוש שני, EMA (אורך), ביצוע בפתיחת היום הבא או בסגירה, עמלות.
**תיק:** הון, גודל פוזיציה, מקסימום פוזיציות, תקרת חשיפה (מעל 100% = מינוף), ריבית מזומן (מק"מ אמיתי / קבועה / אפס), מרווח הלוואה.

## הנחות מידול (חשוב להכיר)

- **נר פריקה:** היום שבו ה-RSI חוצה מתחת לסף, יחד עם כל שאר התנאים (אפשר לעבור ל"כל יום מתחת לסף").
- **RSI:** Wilder, יומי, על סגירה מותאמת לפיצולים (בלי דיבידנדים).
- **פקודת כניסה:** Buy-stop ב-high של נר הפריקה + באפר; מילוי בפתיחה אם היא מעל הטריגר ובתוך התקרה; אין מילוי באותו יום אם הפתיחה מעל התקרה. הפקודה חיה `תוקף` ימים; מדי יום אחרי הסגירה התנאים נבחנים מחדש, ואם ה-high נמוך יותר הטריגר יורד.
- **סטופ:** מחושב ממחיר הכניסה. בנרות יומיים לא ידוע הסדר בתוך היום; אם המחיר נגע בסטופ ביום הכניסה העסקה נעצרת (הנחה שמרנית). פתיחה מתחת לסטופ = יציאה בפתיחה.
- **RVOL:** נפח יומי מלא מול ממוצע ימים קודמים, ביום הכניסה (פרוקסי לבדיקה בדקות האחרונות, שאין לה נתונים היסטוריים).
- **יציאות לפי RSI:** נקראות בסגירה ומבוצעות בפתיחת היום הבא (או בסגירה באותו יום). אחרי המימוש הראשון הסטופ עובר ל-break-even. שבירת EMA = סגירה מתחתיו, ורלוונטית ליתרה בלבד.
- **תיק:** כל פוזיציה מקבלת אחוז קבוע מההון בסגירה הקודמת; עסקאות שחורגות ממקסימום הפוזיציות או מתקרת החשיפה מדולגות (במקרה של תיקו באותו יום: לפי סדר אלפביתי). שווי הפוזיציות נמדד לפי עלות הכניסה לצורך חישוב המזומן (קירוב).
- **מדד ההשוואה:** S&P 500 Total Return; ריבית מק"מ מ-`^IRX`.

## מגבלות

- **הטיית הישרדות:** המאגר הוא חברות שבמדד היום. משפיע במיוחד על אסטרטגיות בלי סטופ.
- **PEG:** אין היסטוריה חינמית. הסינון (אם מופעל) משתמש בערך של היום ולכן אינו תקף לבק-טסט.
- **נתוני דקה היסטוריים לא זמינים**, ולכן RVOL הוא קירוב.
- **שווי שוק נקודתי** = מחיר × מספר מניות היסטורי מ-Yahoo (זמין מ-2015). לכן סימולציה בשווי שוק נקודתי מתחילה ב-2016.
- **Overfitting:** כל הרצה היא ניסיון נוסף. השתמש בפיצול אימון/בדיקה ובלשונית "היסטוריית הרצות", וכוונן רק על תקופת האימון.
- דיבידנדים של המניות המוחזקות, מסים, ומרג'ין קול לא מדומים.
